RLPlayer 2.0.0 正式发布版（自包含）
================================================================================

解压后双击 RLPlayer.exe 即可。不需要安装 .NET、VC++ 运行库、WebView2 或任何解码器。

建议解压到**非系统盘、不需要管理员权限**的目录（例如 D:\RLPlayer）。
不要放进 C:\Program Files —— 那里写入需要管理员权限，会导致设置与缓存保存失败。

--------------------------------------------------------------------------------
一、为什么是「自包含」
--------------------------------------------------------------------------------
声音链路与界面所需的运行库、解码器、GPU 核全部在本目录：

  RLPlayer.exe          启动器（托盘 + 内置 WebView2 无边框窗口）
  rtaweb.exe            播放服务 + 本地界面（默认 127.0.0.1:8899）
  rtagpu.dll            AMD GPU 核（25 种 AMD 架构的多架构 fat binary）
  rtagpu_cuda.dll       NVIDIA CUDA 核（CUDA 12.9；没有 N 卡时不会被加载）
  amdhip64_7.dll        AMD HIP 运行库（GPU 加速所需，已随包内置）
  WebView2Loader.dll    内置界面加载器
  WebView2Runtime\      内置 WebView2 固定运行时（不依赖系统是否装过 WebView2）
  ffmpeg.exe            解码器（FLAC / MP3 / APE / OGG / WMA / ALAC / AAC ...）
  ffprobe.exe           媒体信息探测
  asio_probe.exe        ASIO 驱动预检（避免第三方驱动把播放器带崩）
  data\                 内置数据（OPRA 耳机 EQ 索引等）
  tools\                命令行工具（分析 / 测量 / 诊断，可在终端直接用）
  LICENSE               GPL-3.0 许可证全文
  THIRD-PARTY-NOTICES.txt  第三方组件授权说明（务必看一眼）
  README.txt            本文件

--------------------------------------------------------------------------------
二、第一次打开
--------------------------------------------------------------------------------
1. 双击 RLPlayer.exe
2. 首次启动会让你**选择音乐文件夹**
3. 选好后等它扫完（15000 首约 3 秒）
4. 默认直接显示「专辑」视图

扫描期间可以正常操作，不用等。

--------------------------------------------------------------------------------
三、你的数据在哪
--------------------------------------------------------------------------------
**全部在程序目录内，不写注册表，不往 AppData 塞东西。**

  rlplayer-settings.conf    设置
  rlplayer-library.conf     音乐库根目录列表（每行一个）
  rlplayer-playlist.txt     当前播放队列
  rlplayer-favs.json        收藏
  rlplayer-savedqueues.conf 保存的歌单
  data\                     曲库索引、封面缓存、房间校正集
  covercache\               在线补全的封面缓存
  artistimg\                艺术家头像缓存
  rlplayer-playback.log     播放日志（排查问题用）

所以换机器时，把整个目录拷过去，设置和曲库索引都跟着走。

--------------------------------------------------------------------------------
四、卸载
--------------------------------------------------------------------------------
直接删掉整个目录。没有残留。

--------------------------------------------------------------------------------
五、常见问题
--------------------------------------------------------------------------------

Q: 打开后黑屏 / 白屏？
A: 检查 WebView2Runtime 目录是否完整。若被杀毒软件隔离了 WebView2Loader.dll，
   加白名单后重新解压。

Q: 没声音？
A: 设置 → 输出 → 设备，确认选的是你的 DAC / 声卡。
   如果显示「DEVICE_IN_USE」，说明该设备被别的程序独占（常见于另一个播放器、
   或本程序的另一个实例）。

Q: GPU 徽标不亮？
A: 设置 → 输出 → GPU，看是「可用」还是「不可用」。
   AMD 需要 RDNA 及以上；NVIDIA 需要驱动支持 CUDA 12.x。
   不可用不影响功能，会自动用 CPU 计算。

Q: 封面 / 头像不显示？
A: 设置 → 元数据补全 → 打开「自动补全」。首次会慢一点，之后走缓存。
   搜不到的就留空 —— 我们不会拿一张不相干的图凑数。

Q: 能转移设置到另一台机器吗？
A: 能。整个目录拷过去即可（见上面「三、你的数据在哪」）。

Q: 为什么放进 Program Files 会出问题？
A: 那里的写入需要管理员权限，而 RLPlayer 的配置、索引、缓存都写在程序目录内。
   放在普通目录（如 D:\RLPlayer）就没这个问题。
