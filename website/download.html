Before you install

装之前要知道的

不收集任何数据

播放、曲库、设置全部只在本机。没有后台遥测，没有账号体系。

不联网也能用

解码、升频、滤波、DSD 全是本地计算。联网只影响在线更新、AI 整理、封面与歌词抓取。

AI 需要自己的 Key

在设置里填 DeepSeek 或兼容网关的 API Key。不填也能用全部本地功能。

开源可自编译

GPL-3.0-or-later，源码在 GitHub。第三方组件逐条列在包内 THIRD-PARTY-NOTICES.txt。

SmartScreen 提示

没买代码签名证书，Windows 可能提示「未知发布者」。点「更多信息 → 仍要运行」即可。

关闭窗口不退出

点 × 只是收进托盘，音乐继续放。真正退出要右键托盘图标。
