## オーディオチェーン

`Capabilities · 01–04`

デコード、アップサンプリング、フィルタリング、DSDモジュレーションの各ステップを設定で自在に変更可能。信号チェーン上で現在の動作状況をリアルタイムに確認できます。

### 01 · オーディオチェーン

**信号がどう処理されているか、すべてのステップを可視化**

ソースファイルから出力機器まで、サンプリングレート、音声処理、Bit-Perfect状態を直感的に把握。元のサンプルが維持されているか、どの設定が音を変えたのか、信号チェーンが明確に伝えます。

**信号チェーン（概念図）**

- **デコード** — ストリーミングチャンク分割 · FLAC / DSF / WAV
- **マトリクス** — マルチチャンネルダウンミックス · 2.0 – 7.1.4
- **イコライザー** — 20バンド PEQ · バイパス直通可能
- **キャリブレーション** — コンボリューション IR · ルーム音響補正
- **アップサンプリング** — 最大 1536 kHz · 79種類のフィルター
- **音量** — ReplayGain · 0 dB 直通
- **ディザ** — TPDF / NS9 · LNS15
- **出力** — WASAPI 排他 · ASIO / UPnP

### 02 · フィルタリング

**根拠を持って選べる、79種類のフィルタープリセット**

リニアフェーズ、ミニマムフェーズ、ミックスフェーズ、2ステージフィルタリングなど多彩な再構成方式を提供。アーカイブ済みの周波数応答と品質実測データを参考に、帯域幅、阻止帯域減衰量、過渡特性を把握したうえで最適なプリセットを選択できます。

- 1x / Nx 個別選択（Nx は 1x に追従可能）
- 位相はプリセット追従または手動オーバーライドが可能
- タップ数、阻止帯域減衰量、遷移帯域を柔軟に変更可能

### 03 · PCM アップサンプリング

**高倍率 PCM アップサンプリング、同族サンプリングレート優先戦略**

「同族優先」「厳密な同族」「互換変換」の3つのポリシーを提供し、アップサンプリングの挙動を明確化。44.1 kHz系列の 1411.2 kHz や 48 kHz系列の 1536 kHz をカバー。実際の出力は接続機器とドライバーに依存します。

### 04 · DSD アップサンプリング

**最大 DSD1024、高倍率処理も高精度に実行**

PCM から DSD への変換および同族 DSD レート変換に対応し、最大 DSD1024 をサポート。1〜7次のモジュレーションと安定性保護を組み合わせ、機器の能力に応じて ASIO ネイティブ DSD または DoP 出力を選択できます。

- モジュレーターファミリと次数を変更可能、保護適用後の実際の値を明示
- DoP と ASIO ネイティブの2つのパスをドライバー機能に応じて選択
- DSD ソースはビットパーフェクト直通または条件付きデコードを選択可能

## 音響チューニングと音楽メタデータ

`Tuning · 05–10`

測定、補正、解析、整理――「良い音」を構成する要素を検証可能な形に分解します。

### 05 · GPU

**AMD と NVIDIA、GPU によるオーディオ演算アクセラレーション**

AMD HIP および NVIDIA CUDA のデュアルバックエンドを搭載し、対応するアップサンプリングや畳み込み演算をGPUへオフロード。GPUの認識状態や現在のトラックで実際に加速が効いているかを明示し、処理状態を一目で確認できます。

### 06 · オーディオ解析

**ダイナミクス、音質、再エンコードの痕跡を1画面で把握**

ラウドネス、ダイナミックレンジ、トゥルーピーク、クリッピング、周波数スペクトルなどの解析結果を集約表示。カットオフ周波数やスペクトルの急峻な減衰、信頼度スコアを組み合わせ、非可逆圧縮からの再エンコードや帯域制限の兆候を提示します。

> 解析はファイルの読み取りのみで行われ、テスト音の再生は不要です。結果は判断の手がかりを提供するものであり、音源の品質を断定するものではありません。

### 07 · PEQ とヘッドホン EQ

**好みのサウンドを追求できる、20バンドパラメトリックイコライザー**

バンドごとに周波数、ゲイン、Q値、フィルタータイプを個別に調整可能。曲線のドラッグ操作にリアルタイムで追従します。OPRA ヘッドホン補正プリセット、自動プリアンプ、バイパス機能を備え、正確な補正と好みの音作りを両立できます。

### 08 · ルーム音響補正

**スピーカーを、あなたの部屋に最適化**

測定ウィザードと補正フィルターにより、部屋の音響とスピーカーが引き起こす周波数応答の乱れを補正。測定用マイクの校正ファイル、REW / AutoEq のパラメトリックEQテキスト、WAV形式のインパルス応答（IR）のインポートに対応します。

### 09 · AI 音楽メタデータ

**1曲から広がる、豊かな音楽背景の探求**

AI連携により、アルバム、楽曲、アーティスト、関連作品の情報を自動検索・整理。構造化された表示とローカルキャッシュにより、音楽の背景情報をスムーズに閲覧・再確認できます。

> APIキーはお客様ご自身でご用意ください。引用、外部リンク、「AIによる知識」を明示的に区別して表示します。

### 10 · カバーアートと歌詞

**ライブラリに彩りあるアートワークと、楽曲の物語を**

音声ファイルの埋め込みタグ、ローカル画像、オンラインデータソースを統合し、アルバムアート、歌詞、楽曲情報を自動補完。スクロール同期歌詞やメタデータ整理に対応し、コレクションを美しく整えます。

## 音楽を深く理解し、多彩な再生環境へつなぐ

`Platform · 11–16`

多言語、歌詞表示、ネットワーク配信、オープンソース――再生機能にとどまらない広がりを提供します。

### 11 · 多言語対応 UI

**7つの言語に対応したインターフェース**

日本語、英語、中国語、フランス語、ロシア語、スペイン語、アラビア語に対応。手動切り替えまたはシステム言語への自動追従が可能です。

### 12 · 歌詞翻訳

**言葉の意味まで味わう歌詞体験**

AI による歌詞翻訳、発音表記（ローマ字/ピンイン）、日本語ふりがな付与、繁体字・簡体字変換に対応し、原文との対訳表示を保持します。

### 13 · 正式リリース版

**Windows と macOS の完全スタンドアロンパッケージ**

Windows 10 / 11 x64 および macOS 13+（Apple Silicon）向けに完全版パッケージを提供。UIランタイム、デコーダー、必要なGPUコンポーネントを内蔵し、オーディオドライバーさえあれば導入後すぐに使用可能です。アプリ内アップデートチェックにも対応。

### 14 · UI とインタラクション

**複雑なオーディオ設定をわかりやすく解説**

主要なオーディオ設定項目には解説テキストが用意されており、信号チェーンとステータス表示で実際の処理結果を即座に確認できます。

### 15 · ネットワーク配信

**ネットワークプレーヤーやアクティブスピーカーへ音楽をワイヤレス転送**

同一LAN内の UPnP / DLNA 対応機器へ音楽をストリーミング配信し、PCのライブラリをお手持ちのオーディオシステムに統合可能。macOS 版では AirPlay 配信にも対応しています。

### 16 · コンテンツ連携

**EMBY・Navidrome・NAS に接続**

LAN 上の NAS や SMB／NFS 共有を直接マウントし、Emby・Navidrome・Plex などの音楽サーバーに接続。クラウドのライブラリもローカルファイルと同様にブラウズ・再生でき、事前のダウンロードは不要です。

## 仕様と制限事項

`Scope`

最大出力スペックは接続機器、ドライバー、および選択した処理パスに依存します。DoPの利用可能レートはキャリア周波数により制限されます。オーディオ解析は判断の目安を提供するものです。AIおよびオンラインメタデータ機能はネットワーク環境、サービス設定、データソースに依存します。Bit-Perfect はサンプルの不変性を示す指標であり、音質の良し悪しを直接評価するものではありません。アップサンプリングやEQ処理を有効にした場合、ビットパーフェクト直通とは同時に成立しません。
