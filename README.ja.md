## 主な機能

- **AMD と NVIDIA、GPU によるオーディオ演算アクセラレーション** — AMD HIP および NVIDIA CUDA のデュアルバックエンドを搭載し、対応するアップサンプリングや畳み込み演算をGPUへオフロード。GPUの認識状態や現在のトラックで実際に加速が効いているかを明示し、処理状態を一目で確認できます。
- **ダイナミクス、音質、再エンコードの痕跡を1画面で把握** — ラウドネス、ダイナミックレンジ、トゥルーピーク、クリッピング、周波数スペクトルなどの解析結果を集約表示。カットオフ周波数やスペクトルの急峻な減衰、信頼度スコアを組み合わせ、非可逆圧縮からの再エンコードや帯域制限の兆候を提示します。
- **好みのサウンドを追求できる、20バンドパラメトリックイコライザー** — バンドごとに周波数、ゲイン、Q値、フィルタータイプを個別に調整可能。曲線のドラッグ操作にリアルタイムで追従します。OPRA ヘッドホン補正プリセット、自動プリアンプ、バイパス機能を備え、正確な補正と好みの音作りを両立できます。
- **スピーカーを、あなたの部屋に最適化** — 測定ウィザードと補正フィルターにより、部屋の音響とスピーカーが引き起こす周波数応答の乱れを補正。測定用マイクの校正ファイル、REW / AutoEq のパラメトリックEQテキスト、WAV形式のインパルス応答（IR）のインポートに対応します。
- **1曲から広がる、豊かな音楽背景の探求** — AI連携により、アルバム、楽曲、アーティスト、関連作品の情報を自動検索・整理。構造化された表示とローカルキャッシュにより、音楽の背景情報をスムーズに閲覧・再確認できます。
- **ライブラリに彩りあるアートワークと、楽曲の物語を** — 音声ファイルの埋め込みタグ、ローカル画像、オンラインデータソースを統合し、アルバムアート、歌詞、楽曲情報を自動補完。スクロール同期歌詞やメタデータ整理に対応し、コレクションを美しく整えます。
- **ネットワークプレーヤーやアクティブスピーカーへ音楽をワイヤレス転送** — 同一LAN内の UPnP / DLNA 対応機器へ音楽をストリーミング配信し、PCのライブラリをお手持ちのオーディオシステムに統合可能。macOS 版では AirPlay 配信にも対応しています。
- **EMBY・Navidrome・NAS に接続** — LAN 上の NAS や SMB／NFS 共有を直接マウントし、Emby・Navidrome・Plex などの音楽サーバーに接続。クラウドのライブラリもローカルファイルと同様にブラウズ・再生でき、事前のダウンロードは不要です。
