# RLPlayer 功能盘点（介绍视频用）

> 盘点时间：2026-10-27 · 依据：仓库代码、`docs/` 纪要、各版本发布说明、`tools/rtaweb.cpp` 的 113 个 API 端点、真实界面截图、以及本机实测数字。
> 目的：**先对齐"我们有什么、什么值得拍、什么不能吹"**，再写提示词。

---

## 0. 一句话定位

**RLPlayer 是一个 Windows 上"可测量、可验证"的本地高保真播放器**：
它不只是把文件放出来，而是把整条信号链（解码 → 滤波升频 → 卷积/EQ → 音量 → 量化 → 独占输出）
的每一步都做成**可见、可调、可自证**的东西。

- 不是流媒体客户端，不是"网易云套壳"，不是播放器皮肤。
- 用户画像：有本地曲库（几百到上万首）、有 DAC/耳放/音箱、在意"这一版和第上一版声音有没有变"的人。
- 差异化关键词：**bit-perfect 自证**、**参数级透明**、**全链路 GPU 且可验证**、**AI 打理曲库但标注来源**。

## 1. 能力盘点（七大域）

### A. 曲库与元数据
| 能力 | 证据 / 数字 | 视频表现 | 可信度 |
|---|---|---|---|
| 原生标签解析（FLAC/WAV/MP3/OGG/APE…） | 扫描 **117×**（15000 首 5.49 min → 2.81 s）；WAV 内嵌标签 **625×** | 数字计数动画 + 进度条 | 实测 |
| CUE 整轨自动分轨 | 解析 UTF-16/UTF-8/GBK + 1/75 帧偏移；播放入口带 cue 区间 | 一张整轨 → 多条曲目"裂开" | 实测 |
| DSD 直读（DSF/DFF）+ 流式解码 | 大 DSD 首帧 **8.2 s → 651 ms**、峰值内存 **2071 MB → 59 MB** | 内存曲线"断崖"对比 | 实测 |
| 在线补全（标签/封面/歌词） | 封面覆盖 **176/177（99.4%）**；曲库专辑 301 → 归并 181 | 封面墙从灰块"点亮" | 实测 |
| 标签写回 / 手动纠错 | `/api/writeback`、`rtatag.exe`（store show/set） | 一条标签被改写的近景 | 实测 |
| 收藏 / 歌单 / 最近 / 队列 | `/api/fav`、`/api/pl`、`/api/sq`（保存队列） | 拖拽入队、歌单生成 | 实测 |

### B. 播放与输出链路
| 能力 | 证据 / 数字 | 视频表现 | 可信度 |
|---|---|---|---|
| WASAPI 独占 / 共享、ASIO（含原生 DSD） | 双注册表视图枚举，7 个驱动含 CLSID | 设备列表逐项亮起 | 实测 |
| **bit-perfect 一键直通** | 源采样率 / 无抖动 / 0 dB / 无 EQ·IR / 独占，逐项勾选 | 六个条件依次打勾 → 徽标变绿 | 实测 |
| **六态徽标** | bit-perfect / 非 bit-perfect × PCM-PCM / PCM-DSD / DSD-DSD 升频（含降级原因 title） | 底栏徽标切换特写 | 实测 |

### C. 升频与滤波（最能"秀参数"的部分）
| 能力 | 证据 / 数字 | 视频表现 | 可信度 |
|---|---|---|---|
| **79 个命名滤波预设** | 线性/最小/混合相位、poly-sinc、gauss、sinc、closed-form、minring | 预设列表滚动 + 频响曲线随之变形 | 实测 |

| 44.1k → 384k（8.7 倍） | 支持到设备最高档，不超 384k | 采样杆加密 | 实测 |

## 2. 真正的"重点"（只有这四个值得当主卖点）

1. **bit-perfect 不是口号，是逐项自证**
   六个条件逐条打勾、六态徽标、信号链每个节点标注 GPU/CPU → 观众能"看见"它没动比特。
2. **参数级透明：79 个预设 + 每相位抽头地板**
   别的播放器给一个"高/中/低"，我们给 79 个命名预设，还能看到 4 抽头 vs 512 抽头的 3.3 dB 差距。
3. **全链路 GPU，且"真跑了才亮"**
   平凡 kernel 验算 + 绿点只代表本次真参与；显卡不支持就老实退回 CPU（结果一致）。
4. **AI 只做"打理"，且标注来源**
   自动整理标签/封面/简介，但每条都标来源；找不到就写"未找到权威来源"，不冒充。

> 其余能力（歌词、主题、托盘、投放）是"质感分"，放在快剪里，不要单独成段。

## 3. 不能吹 / 不要出现

**禁用词（全程零出现，含拼音、Logo、域名、截图里的字样）**
- ROON（含 opra.roon.app）
- HQPlayer（含 hqplayer、HQP、Signalyst）
- RTA（含 rtaweb/rtagpu/rtaplay 等可执行文件名——拍界面时避免露出 tools 目录）

**不能吹（会被真机打脸）**
- ❌ "支持 SACD ISO / DST"（未实现）
- ❌ "标准 NAA / networkaudiod 兼容"（已删除，两机方案是自有 RTANet）
- ❌ "DSD 输出全是原生"（DoP 为主，原生仅 ASIO 同速率）
- ❌ "7 阶调制器全速率稳定"（DSD64 会自动降 5 阶并说明）
- ❌ "GPU 卷积与 CPU 逐位一致"（**当前包仍有跨块拖尾缺陷，见下方警告**）
- ❌ "零延迟" / "最好听" 这类主观绝对化表述
- ❌ 编造数字（上一版视频里的 −189 dB、705.6 kHz、2.0 ms 都不是我们的实测值）

**⚠️ 视频里若要提 GPU 卷积，必须等新包**
2026-10-27 00:39 的修复（`0eb859b`）才把 GPU 卷积改成跨块有状态；**已发布的 1.5.6 仍是旧实现**。
本机实测（4096 块粒度、IR=8192）：GPU 与 CPU 的差信号 RMS 比信号本身还高 **+2.28 dB**。
新包出来之前，视频只能说"GPU 加速升频/卷积"，**不要展示精度对比数字**。
