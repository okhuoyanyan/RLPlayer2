# RLPlayer 介绍片 · 分镜 v1（4K60 / 中文旁白 / 中文字幕）

> 时长 **175 s**（允差 ±5 s）· 3840×2160 · 60 fps · 中文旁白 + 中文字幕 · 无真人出镜
> 本文件是**可直接执行**的分镜：每一镜都有画面、运镜、屏显、旁白、时长、素材来源、验收判据。
> 禁用词（全片零出现）：Roon / HQPlayer（含缩写与域名）/ RTA。对外技术对标统一说「对标专业级升频引擎」。

| 项 | 值 |
|---|---|
| 旁白 | TTS，中文男声，30 岁上下，冷静、偏纪录片解说，不要播音腔、不要喊 |

| 音效 | 仅在数字落定、曲线收尾、转场处用轻微 UI 音（−24 dBFS 以下） |

### 1.4 TTS 选型（「不能断字不清、不能生硬」的落地方案）

**首选（云）**：火山引擎「豆包语音合成大模型」中文男声 / MiniMax speech-2.5 / Azure zh-CN-YunyeNeural。
**备选（本地、离线）**：CosyVoice2（开源）——效果接近云服务，且不受额度限制。
**明确不用**：系统自带 SAPI、Edge 免费 TTS（就是「机械音」的来源）。

**三个硬要求（不做就会翻车）**
1. **数字改写**：TTS 文本里数字一律写中文（「两秒八一」「七十九种」），屏幕字幕才显示阿拉伯数字；否则会逐位念或念错。
2. **长数字不念**：像「−144.6 dB」「384 kHz」「compute_121」这类只上屏、不进旁白；旁白改说人话（「压到噪声底下」）。
3. **断句用标点控制**：逗号 180 ms、句号 380 ms、破折号 250 ms；不用 SSML 强插停顿（大模型 TTS 对 SSML 支持不一致）。

## 二、旁白全文（可直接投喂 TTS，一次合成后按句切分对齐）

> **S0**
> 这是一台播放器。它不猜你喜欢，也不替你选歌，只做一件事——把你硬盘里的歌，原原本本地放出来。

> **S1**
> 先看一眼你的曲库。一万五千首，第一次全量扫描，两秒八一。不是两分钟，是两秒八一。封面、标签、歌词，CUE 整轨分轨，扫完就已经整理好了。

> **S2**
> 剩下的它自己来。封面、年份、流派、艺人，多源自动补全，封面覆盖率九成九。想再深一点，AI 会把专辑、乐团、录音版本整理成一份资料——每一条都标出处；查不到，它就写查不到。

> **S3**
> 然后是升频。很多播放器只给你高、中、低；这里给你七十九种引擎。为什么要折腾？因为升频有三个坑：高频塌、镜像混、过载爆。前两个是可以量出来的。同一首歌，旧设置每相位只有四个抽头，两万赫兹掉三点三分贝；把地板抬到五百一十二个抽头，掉的就变成零。阻带也从负六点六分贝，一路压到负一百四十四点六。

> **S4**
> 声音出门之前，还得跟房间和解。二十段参数均衡，拖一个点，曲线实时跟着走；六千多款耳机的校正曲线，一键套上；房间的驻波，一段扫频就能测出来。REW 导出的文件，直接能用。

> **S5**
> 它是免费的，也不会变成收费的。代码按 GPL-3.0 开源，Windows 是主线，社区的 macOS 分支，同一个协议往前走。

> **S6**
> 解压，双击，就能听。解码器、显卡加速、界面运行时，都在包里。没有订阅，没有广告，没有登录。就这些。

**字数统计**：约 570 字 → 按 4.3 字/秒约 133 s 语音，留 42 s 给「看画面不说话」的呼吸位。

## 五、验收判据（成片自检，逐条打勾）

1. 时长 175 ± 5 s；4K60 恒定帧率；无掉帧（ffprobe -count_frames 校验）。
2. 禁用词零命中：对成片音轨转写文本 + 全部屏显文字双检（Roon / HQPlayer / RTA 及大小写变体）。
3. 每一条屏显数字都能在仓库/实测记录里找到出处（全片 11 个数字，逐条对照）。
4. 旁白与字幕逐句对齐，偏差 < 150 ms；无断字、无错读（尤其「两秒八一」「七十九」「六百三十二」）。
5. 所有「界面」画面均为真实录屏，无一处合成假 UI。
6. 响度 −16 LUFS ±0.5，真峰值 ≤ −1 dBTP。
7. 首 3 s 内出现第一个视觉钩子；每 8 s 之内必有一次画面变化。
8. 片尾静帧 3 s，不含二维码/联系方式（如需另出一版）。

## 六、4K60 制作管线（现实可行的做法）

| 段 | 做法 | 说明 |
|---|---|---|
| 真实界面段 | WebView2 宿主窗口 1920×1080 CSS + DPR=2 → CDP 截屏得 3840×2160 真像素 | UI 是矢量，2 倍像素下边缘锐利，不做后期放大 |
| 操作录制 | CDP screencast 60 fps（JPEG q=92）或 Playwright 录制后重采样 | 光标可后期加，避免录到真实光标抖动 |
| 数据动效段 | Canvas/WebGL 以 t 为纯函数渲染 → 4K60 逐帧截取 → ffmpeg 合成 | 可无限重渲，改文案不用重录 |
| 合成 | ffmpeg：HEVC Main10、CRF 17、-movflags +faststart | 4K60 H.264 需 45 Mbps 才不掉细节；HEVC 约一半 |
| 配音 | TTS 一次合成全篇 → 按句切分 → 与分镜对齐 | 数字先改写成中文再合成 |
