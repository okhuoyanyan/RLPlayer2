# Dither / Noise Shaping 实现纪要（Round 3）

代码：[src/dsp/dither.h](src/dsp/dither.h)　测试：[tests/test_dither.cpp](tests/test_dither.cpp)

## 1. 实现结构

误差反馈型噪声整形：

```
u[n] = x[n] + Σ h[k]·e[n-k]        （反馈过去的量化误差）
y[n] = Q(u[n] + dither[n])          （重新量化到目标位深）
e[n] = y[n] - u[n]
⟹  Y(z) = X(z) + NTF(z)·E(z)
```

取 **NTF(z) = (1 − r·z⁻¹)^N**：直流处 N 阶零点（把量化噪声推向高频），高频增益 (1+r)^N。
系数 `ntf[k] = C(N,k)·(−r)^k`，反馈 FIR 取 `h[k] = ntf[k], k≥1`。
`r` 可调（1.0 = 最激进；略小于 1 可压制超声段增益）。

**严格按手册设定阶数，未臆造 NS2/NS3/NS6/NS7/NS8**（手册抖动表只有 NS1/NS4/NS5/NS9/LNS15 + 4 种抖动）。

## 2. NTF 理论幅频特性

| 整形器 | 阶数 | DC | 20 kHz | Nyquist |
|---|---|---|---|---|
| NS1 | 1 | 深零点 | −3.13 dB | +6.02 dB |
| NS4 | 4 | 深零点 | −12.52 dB | +24.08 dB |
| NS5 | 5 | 深零点 | −15.65 dB | +30.10 dB |
| NS9 | 9 | 深零点 | −28.17 dB | **+54.19 dB** |
| LNS15 | 15 | 深零点 | −46.95 dB | +90.31 dB |

与手册描述完全吻合：NS1 温和、NS5"相当激进"、NS9"非常激进"、LNS15 陡斜率。
**注意**：LNS15 的超声增益高达 90 dB，这正是手册强调它"专为 16x 倍率（705.6/768 kHz）设计"的原因——噪声被推到远超音频带的位置。

## 3. 实测结果（−60 dBFS / 1 kHz 正弦 → 16 bit @ 176.4 kHz）

| 整形器 | 带内噪声 (0–20 kHz) | 带外 (20 k–88.2 k) | 稳定性 |
|---|---|---|---|
| none | −103.2 dB | −99.5 dB | 稳定 |
| RPDF | −101.5 dB | −96.1 dB | 稳定 |
| TPDF | −99.9 dB | −94.3 dB | 稳定 |
| Gauss1 | −98.5 dB | −93.1 dB | 稳定 |
| shaped | −102.6 dB | −97.3 dB | 稳定 |
| **NS1** | **−112.8 dB** | −95.0 dB | 稳定 |
| **NS4** | **−126.7 dB** | −79.6 dB | 稳定 |
| **NS5** | **−130.6 dB** | −74.1 dB | 稳定 |
| **NS9** | **−145.0 dB** | −51.2 dB | 稳定 |
| **LNS15** | **−149.6 dB** | −16.2 dB | 稳定 |

**带内噪声随阶数单调下降**（−112.8 → −126.7 → −130.6 → −145.0 → −149.6 dB），带外对应上升——整形器行为完全正确。

关键对照：**NS9 带内比 TPDF 低 45.4 dB**，代价是带外噪声高 43.1 dB（由 DAC 模拟滤波器负责滤除）。

## 4. 验证要点（客观判据，非主观听感）

1. NTF 在直流处为深零点（数值上 −6000 dB）
2. 阶数越高，20 kHz 处抑制越强（单调性）
3. NS9 高频增益 > 50 dB（对齐手册"非常激进"的描述）
4. 实测带内噪声随阶数单调下降
5. NS9/LNS15 带内比 TPDF 低 15 dB 以上（实测 45.4 / 50.0 dB）
6. NS9 带外高于 TPDF（噪声确实被"推出去"而非"消失"）
7. **全部整形器发散保护触发 0 次**（误差反馈在高阶下稳定）

## 5. 已知不足 / 待改进

- `shaped` 抖动目前只比 TPDF 好 2.7 dB，可通过提高整形抖动幅度并独立设定其 NTF 改善
- 目前只覆盖定点 PCM 输出；还需支持"仅抖动不整形"与"仅整形不抖动"的独立组合（手册里 `none` 可与整形搭配）
- `r`（零点半径）已实现但尚未暴露为可调参数，后续用于对齐不同采样率下的最优激进程度
- 未做 DAC bits 与输出位深的联动（手册 4.4 推荐 Holo=20 / Denafrips=19 / LAiV=18）
