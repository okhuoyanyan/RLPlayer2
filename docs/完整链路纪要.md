# 完整 DSP 链路接入纪要（Round 10）

代码：[src/engine/pipeline.h](src/engine/pipeline.h)　测试：[tests/test_chain.cpp](tests/test_chain.cpp)

## 1. 信号链顺序（对齐手册第 4~7 章）

```
1) 解码缓冲（源采样率，解交错为 double 平面）
2) Matrix 路由/混合    增益可为 dB 或线性；负增益 = 反相（M/S 处理）
3) 每输出声道处理链    IIR EQ（双二阶级联）+ 延迟
4) 卷积               均匀分块 FFT，零延迟
5) 重采样到目标采样率  1x / Nx 可选不同滤波器
6) 音量               在目标采样率上，带渐变
7) 抖动/噪声整形 → 输出位深
```

三条路径判定同步收紧：**逐位直通要求以上【全部】旁路**（此前只检查重采样与整形）。

## 2. 实测结果（8 套测试全绿）

| 验证项 | 结果 |
|---|---|
| 全旁路回归 | **逐位相同** |
| EQ（+6 dB peak @1 kHz） | 实测提升 **6.000 dB**（设定 6.000 dB），且不再直通 |
| Matrix（L+R 混合） | 两输出声道内容一致，且不再直通 |
| 卷积（IR = 单点 0.5） | 最大偏差 **0.50 LSB**，超 1.5 LSB 的样本 **0 / 47900** |
| 音量（−6.0206 dB） | 逐样本 **0 个不匹配** |
| 组合链路（5 阶段 + 升频） | 五个阶段全部生效，48000 → 96000 帧 @96 kHz |

## 3. 本轮修掉的一个真 bug

**卷积分块只处理整块，尾部不完整块会被清零。**
若缓冲长度不是 convBlock 的整数倍，**每个缓冲末尾都丢一小段音**（约 1024 样本以内）。
已改为：把不足部分补零送进卷积器，只回写实际样本数。

## 4. 又一个「判据错了」的案例（第 4 次）

卷积测试最初报 **11897 / 47900 个样本不匹配**，看起来像卷积坏了。实际原因：

- IR = 单点 0.5 时，`raw * 0.5` 对奇数 raw **恰好落在 .5 取整边界**上
- FFT 往返引入 1e−16 量级的浮点噪声，决定进位方向
- 约四分之一的样本因此差 **1 LSB**

**这是浮点卷积路径的固有属性，不是缺陷。** 用「逐位相等」去判定必然得到假失败；
正确判据是「误差 ≤ 1 LSB」。修正后实测最大偏差 **0.50 LSB**。

> 这是本项目第 4 次遇到「测试通过/失败与实际对错相反」的情况。
