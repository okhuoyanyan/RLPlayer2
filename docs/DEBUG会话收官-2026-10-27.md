## 新增测试基础设施

- `--remote-debugging-port=<N>`（默认关）：真窗口可直接 CDP，不用再搭注入代理
- `RLPLAYER_PORT=<N>`：强制起独立实例、**跳过接管已有实例** ⟹ 任何代理都能在不碰用户 8899 的前提下拿铁律 11 的真窗口截图
- 踩坑：`get_TargetCompatibleBrowserVersion()` 返回 `nullptr` 时 `CreateCoreWebView2EnvironmentWithOptions` 返回 `0x80070057`，WebView2 会**静默退回 Edge --app**

## 本轮仍未解决（更新到上面各节）

1. **谐波失真在这套指标里不可见**：无损 vs +1% 三次谐波 → 失真版赢 0.34 分；+5% → 赢 1.64 分。
   根因：三次谐波落在「16 个最强谱峰」里被 non_tonal 陷波掉（只动 0.008 dB）；且立方失真是**扩张型**，DR/峰值因子反而升高。
   修法已评估：谐波族能量占比 1~2 人日、H3/H1-电平斜率 1 人日、预回声/瞬态涂抹 2 人日，**合计约 4~5 人日**。
2. **clippedPct 与 runs 口径不一致**（D2）：稀疏单点满幅 → pct=0.0208% 但 runs=0；全库 **110/655 首**如此。
   需产品决策：headline 只在 runs>0 时出数，或门限提到 0.9999。
3. **96/24 母带 vs 44.1/16 差距 18.6 分（应很小）**：其中 non_tonal 10.3 分主要是采样率伪影
   （44.1k vs 96k 的 FFT 窗长差 2.2 倍，同内容漂 13.9 dB 却标「可比」）。
4. **容器覆盖不全**（影响 incomplete 检测）：ALAC/M4A/OGG/Opus/APE/WV/AIFF/DFF 没有统一精确总样本字段，
   这些格式截断仍报 ready。MP3 无 Xing/VBRI 的 CBR 不判（按字节估会偏）。
5. **19 项弹窗没有实机像素截图**：代理那边前台是用户的 8899 实例、`SetForegroundWindow` 被系统拒绝，
   改用同源 JS + 真实 `/api/health` 的 DOM 渲染校验。**这条需要补**（现在有了 `RLPLAYER_PORT`，可以补）。
6. **DSD 的频响四项跨工具不可比**：我们抽到 176.4 kHz、ffmpeg 输出 352.8 kHz，峰值差 2.1 dB、重心 1348 vs 3781 Hz。
   UI 已改为 DSD 源不展示这四项。
