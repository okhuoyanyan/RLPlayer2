# 等响度补偿纪要（Round 59）

代码：src/dsp/loudness.h　测试：tests/test_loudness.cpp

## 1. 手册依据（4.2 Loudness）

手册原文要点：

> Loudness is a volume-adaptive loudness control with adjustable parameters.
> For bass and treble controls, the corner frequency, slope factor and level can be
> adjusted (Parameter 1 to Parameter 6 respectively). Lower bound (Parameter 7) is
> volume setting where at or below, set maximum loudness value is reached.
> Higher bound (Parameter 8) is volume setting where at and above, loudness value
> reaches 0 dB.

物理动机：人耳等响曲线（ISO 226）在小音量下对低频与极高频的敏感度显著下降。
音量拧小时若不补偿，听感会变薄。Loudness 就是按当前音量补回这部分。

## 2. 实现

低音用低架滤波器、高音用高架滤波器；提升量按音量在 [下界, 上界] 之间线性插值：

    音量 <= 下界(P7)  -> 满提升（低音 P3、高音 P6）
    音量 >= 上界(P8)  -> 0 dB
    之间              -> 线性插值

参数（手册 P1-P8 一一对应）：

| 参数 | 含义 | 默认 |
|---|---|---|
| P1/P2/P3 | 低音角频率 / 斜率 / 最大提升 | 100 Hz / 0.7 / +6 dB |
| P4/P5/P6 | 高音角频率 / 斜率 / 最大提升 | 6 kHz / 0.7 / +3 dB |
| P7 / P8 | 下界 / 上界音量 | -30 dB / 0 dB |

## 3. 实测（全部通过）

| 验证项 | 结果 |
|---|---|
| 音量 0 dB（上界） | 无提升，频响完全平坦（100 Hz 与 6 kHz 均 0.0000 dB）|
| 音量 -30 dB（下界） | 满提升 |
| 低于下界 | 截断为满提升 |
| 中点 -15 dB | 低音 +3.00 dB、高音 +1.50 dB（正好一半）|
| **实测频响 @ -30 dB** | **20 Hz +5.88 dB、1 kHz +0.06 dB、12 kHz +2.67 dB** |
| 单调性 | 音量越低提升越大 |

## 4. 本轮抓到的两个问题（一个是库里的真 bug）

### 4.1 测试 bug：单调性判据的初值反了

提升量随音量【下降】而【增大】，因此从 0 dB 开始遍历时是**递增**的。
我把 prev 初值设成了 1e9，第一个值 0.00 就满足 `bd < prev`，立刻误判为非单调。

### 4.2 库 bug：reset() 会永久旁路滤波器

```
// 错：Biquad 把系数与延迟状态存在一起，赋单位滤波器把【系数】也清掉了
void reset() { bass_ = Biquad{}; treble_ = Biquad{}; }

// 对：置 dirty_ 让 prepare() 重建系数
void reset() { dirty_ = true; bass_ = Biquad{}; treble_ = Biquad{}; }
```

**症状极具迷惑性**：第一个被测量的频点（20 Hz）完全正常，
之后的频点全部恰好 0.00 dB。原因是首个频点测量时 dirty_ 仍为 true、
prepare() 还会重建系数；而 reset() 把 dirty_ 留作 false 后，
系数再也不会被重建 —— **滤波器被永久旁路**。

**任何调用过 reset() 的用户都会遇到「滤波突然失效」**，而且第一个频点看着正常，
极易误判为「高频段设计有误」。

## 4.3 接入管线（Round 60）

**用法**：

    rtaplay music.wav --volume -30 --loudness
    rtaplay music.wav --volume -30 --loudness --loudness-bass 8      # 低音最大提升改 8 dB
    rtaplay music.wav --volume -30 --loudness --loudness-bounds -25 -5  # 自定义上下界(P7/P8)

**关键设计**：音量 >= 上界时 bass_db()/treble_db() 均为 0，Loudness::process 直接返回，
因此**这一段是完全旁路**，对比特完美没有任何影响。已用逐位比对实证。

**实测**：

| 验证 | 结果 |
|---|---|
| 0 dB + loudness vs 不带 loudness | **逐位完全相同（1728000 字节）** |
| -30 dB + loudness vs 不带 loudness | **不一致（541066 字节不同）** |
| 全套测试 | 16 套全绿 |

第一行证明旁路正确（比特完美不受影响）；第二行证明补偿确实生效。
**一个功能既要"能生效"，也要"该旁路时真的旁路"——两行缺一不可。**
