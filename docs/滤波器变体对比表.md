## 2. 判据如何严格避免「三个坑」

1. **避开坑 1（截止频率接近 Nyquist 导致冲激退化）**：
   - 所有变体的归一化原型截止频率严格设定在半带区间：`cutoff = 0.5 * (1.0 - transition)`（落在 0.360 ~ 0.4985 之间）。
   - 保证了升频滤波器的真实物理滤波特性，脉冲能量不退化为中心单冲激，时间域指标与群延迟具备真实意义。

2. **避开坑 2（用「峰值前能量 / 总能量」判定对称性）**：
   - 峰值样本自身占近半能量，对称滤波器的「峰值前能量 / 总能量」天然约为 0.25。
   - 本报告与门禁判据严格采用**前/后振铃能量比（pre_post_ratio）**：
     - 线性相位变体前/后能量比精确等于 1.0000（容差 [0.90, 1.10]），峰值位置精确为 0.5000；
     - 最小相位变体峰值位置处于开头（< 0.0100），前/后能量比 < 1.0，能量重心前移数百倍；
     - 混合相位（Intermediate Phase）能量重心严格介于最小相位与线性相位之间。

3. **避开坑 3（倒谱法使用绝对对数幅度地板污染高斯窗）**：
   - 高斯窗阻带可达 -300 dB 以下，若使用绝对对数地板会将深阻带整体压平产生假倒谱项；
   - 最小相位转换严格使用**相对峰值的对数地板（peakMag * 1e-15）**，保证 `-mp` 变体与 `-lp` 变体在有效可听带及阻带范围内的幅频偏差 < 0.04 dB。
