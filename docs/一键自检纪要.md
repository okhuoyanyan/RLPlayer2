## 3. 本轮踩的坑：脚本自身的三个问题

这三个都不是项目问题，而是**脚本本身**的问题——与铁律 3 同一类：

**坑 1：编码**。`write` 工具写的是无 BOM 的 UTF-8，而 PowerShell 5.1 默认按 ANSI(GBK) 读取 .ps1，
中文字节把结尾引号吞掉，脚本直接语法错误且**没有任何报错输出**（静默失败）。
**修法**：写入时加 UTF-8 BOM（`New-Object System.Text.UTF8Encoding($true)`）。

**坑 2：解析别人程序的文本输出**。原来靠正则解析 ctest 的汇总行，脆弱易碎。
**改为看退出码**（`$LASTEXITCODE`），这是稳定的契约。

**坑 3：异步作业没等完**。端点在 `--seconds 9` 到点后才写 WAV，而脚本只等了 4 秒，
于是 wavcmp 报 exit=2（文件不存在）。**改为 `Wait-Job -Timeout`**。
