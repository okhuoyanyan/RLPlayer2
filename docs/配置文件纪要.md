# 配置文件纪要（Round 29）

代码：[tools/rtaplay.cpp](tools/rtaplay.cpp)

## 1. 用法

```powershell
rtaplay music.wav --rate 705600 --taps 262144 --shaper NS9 --volume -6 --gpu `
                  --config eq.txt --ir room.wav --save-config my.conf

# 之后只需
rtaplay music.wav --config my.conf

# 临时覆盖某一项
rtaplay music.wav --config my.conf --rate 176400
```

## 2. 格式与优先级

```
# RTA-Player config (key=value). CLI options take precedence over this file.
rate=88200
bits=24
taps=65536
shaper=NS5
volume=-3
gpu=0
buffer=100
eq=autoeq.txt
ir=room.wav
matrix=0>0:0,1>1:0
device=<端点 ID>
```

**优先级：命令行 > 配置文件。** 实现方式是「配置只填补命令行没设置的项」，
因此 `--config my.conf --rate 176400` 会正确地用命令行覆盖 rate、其余仍取自配置。

## 3. 实测

| 场景 | 结果 |
|---|---|
| 写出配置 | 8 项全部落盘，ASCII 注释（避免 PowerShell 按 ANSI 读出乱码） |
| 用配置回放 | 「应用 7 项」，管线统计吻合 |
| **命令行覆盖** | 「应用 **6** 项」—— rate 被命令行占用，配置项正确跳过 |

第三项是优先级设计正确的直接证据。
