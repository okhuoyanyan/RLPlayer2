**P1 明确未做到的（不要当成已完成）**

5. DSF/DFF 样本是自造二阶 SDM 流（带内噪声 −52.5 dBFS），验证容器+位流读取，非真实母带

## 9. 踩过的坑（别再踩）

### 9.1 子代理换模型：只认官方设置
- **无效（已全部还原）**：改 `~/.dsh/.agent-presets/*`（该目录**不被应用加载**）、改内置预设 `...\dsh\config\agent-presets\code\agent.cordis.yml`、在 `profiles/desktop/cordis.patch.yml` 加 `tool-subagent.agentOptions`（patch 只到 host 层，够不到预设内部行 —— `dsh --dump-config` 实证）
- **唯一有效**：设置 → 子智能体 → 模型选择（官方 0.2.x）
- 版本事实：桌面 app `FileVersion=0.2.1-rc.2`；`~/.dsh/profiles/node_modules` 里 186 个包是 0.1.0-rc.6（**别改**）
- 社区插件都不必要：`dsh-delegate`（已归档）、`yet-another-subagent`（不支持 reasoningEffort）、`agent-team-gui`（同上）

### 9.2 `interrupt_agent`/`send_message` 只对 `spawn_teammate` 队友有效
`subagent` 的一次性激活**无法中止**（`active teammate not found`）。派单前想清楚。

### 9.3 `dsh --dump-config` 只对 web profile 可用
`--profile desktop` 会报 "managed exclusively by the Electron application"。

### 9.4 并行子代理必须用独立 worktree
否则互相覆盖；P1/P2 争 `make_dist.ps1`，必须串行。

### 9.5 其它
- `dist\RLPlayer-1.0.8-win64\` 里的日志是 Lead 验证 Locales 时写入的（不是事故）
- PowerShell `Get-ChildItem -Include *.yml` **不加 `-Recurse` 会静默返回空**
- 编译需显式 `CMAKE_RC_COMPILER`：
  ```
  cmake -G Ninja -S . -B build -DCMAKE_BUILD_TYPE=Release "-DCMAKE_CXX_COMPILER=C:/Program Files/AMD/ROCm/7.2/bin/clang++.exe" "-DCMAKE_RC_COMPILER=C:/Program Files (x86)/Windows Kits/10/bin/10.0.26100.0/x64/rc.exe"
  ```
