## 1. 端点契约（全部实测）

### GET /api/lib/cover?k=<专辑键> —— 只读、零网络
1. 内嵌 / 同目录图（沿用 `Library::albumCover` 的多曲重试 + 负缓存）；
2. `<exe>\covercache\<key>.jpg`（网图正缓存）；
3. `<exe>\covercache\<key>.none`（负缓存，7 天有效）；
4. 都没有 → **404 + 空 body**（实测 bodyLen=0）。

| 路径 | server-side handler 耗时（`COVERGET` 日志） |
|---|---|
| net 命中（磁盘） | min 0.15 / **avg 0.86** / max 11.80 ms（n=228） |
| 404 空（无缓存无内嵌） | min 0.03 / **avg 0.037** / max 0.09 ms（n=72） |
| embed（首次起 ffmpeg） | avg 14.8 / max 133.31 ms；进程内缓存后 < 1 ms |
| 客户端全链路（含发 208 KB） | 1.21 ~ 1.98 ms（n=9） |

- `hasCover=false` 的专辑**不再调 `albumCover`**：否则每张起 3 次 ffmpeg（实测 ~200 ms/张），187 张会把单线程 accept 堵 30 s+ —— 这是"封面页卡死"的老病根。
- `?k=..\..\windows\win.ini` → 404（键先过 `[0-9a-f]` 白名单，否则 fnv 哈希成文件名，杜绝目录穿越）。

### POST /api/lib/cover/prefetch —— 副作用端点
- 进 `kNeedPost`，并在 `is_side_effect_exempt` 里**单独挡掉**（白名单是前缀匹配，`/api/lib/cover` 会顺带放行它）；
  实测 `GET /api/lib/cover/prefetch` → **405** + JSON 错误。
- 立即返回（实测 **21.3 ms**）：`{"ok":true,"queued":172,"candidates":172,"running":true}`
- 队列 = 库里「内嵌无图 且 无 .jpg 且 .none 未过期」；`?k=`（逗号/换行分隔）可指定若干键，且**跳过 .none**（用于重试）。
- 上一轮还在跑 → `{"ok":true,"queued":0,"running":false}`（不排队）。

### GET /api/lib/cover/progress —— 只读
`{"ok":true,"running":bool,"done","total","hit","miss","fail","lastName"}`（纯原子量 + 一次短锁读 lastName，不碰 `mtx_`）

### /api/lib/albums 与 /api/lib/album
新增 `cvSrc`（`embed|net|none`）与 `cvUrl`（net 时给 `/api/lib/cover?k=<key>`），`cv` 保持原义不动（艺术家头像逻辑仍在用）。
实测：net → `"cvSrc":"net","cvUrl":"/api/lib/cover?k=5006f2536b27f744"`；embed → `"cvSrc":"embed"`；none → `"cvSrc":"none"`。

## 2. 并发模型

- **请求线程**：只读库（短锁）+ stat/读文件；**绝不发网络**。
- prefetch：名单在请求线程深拷贝 → detached 线程内 **2 个 worker**（原子游标领号），单张专辑 **6 s 预算**（搜索 ≤2.5 s ×≤2 跳 + 下载 ≤3 s），每轮开工前先看 `g_shutdown`。
- **两跳搜索**：① `专辑名 艺术家` ② 只 `专辑名`。实测艺术家串（同人社团/目录名）拼进去会**降低召回**。
- **查询词去重**：本库 296 个键只对应 ~60 个不同专辑名（见 §5），同一个词只打一次网易。
- 落盘：`.part` → `MoveFileExW` 原子改名；≥2048 B 且 JPEG/PNG/WEBP 文件头才收（不收错误页）。
- 负缓存只在**服务器明确答复没有**（Miss）时写；断网/超时（Fail）不写 —— 否则一次离线运行把 7 天缓存全污染。
- 实测 prefetch 期间 `/api/ping`：**n=50，fail=0，min 0.74 / max 3.80 / avg 1.05 ms**。

## 3. 名称比对（为什么不是"字符串相等"）

Dice 系数（规范化后按**字符多重集**算，规范化 = 全角→半角、小写、去标点/引号、去括号内容、去重音符）：

- ≥ 0.90 → 认（只差繁体/标点/词序/重音，实际同一张）；
- 0.72 ~ 0.90 → 必须**艺术家也对得上**；
- 另有"包含关系"单独放行（`遠景Landscape` vs `遠景Landscape -Touhou Mellow Beats-`，Dice 只有 0.52）；
- **绝不**"名字都不像就拿第一张"：《深空余音》在网易只有《日落日出》，那样会落盘错图且不会自愈。

四轮迭代（172 张候选的命中数，同一份库、同一套判据）：**61 → 72 → 100 → 105**。
