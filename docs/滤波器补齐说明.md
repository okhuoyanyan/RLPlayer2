## 新增的 27 项（全部实测通过）

```
poly-sinc-ext2-short / -medium / -long / -hires-lp / -hires-ip / -hires-mp
poly-sinc-xtr-lp / -mp / -short-lp / -short-mp
poly-sinc-gauss-medium / -halfband / -halfband-s
poly-sinc-hb-xs
poly-sinc-ext
poly-sinc-mqa/mp3-lp / -mp
sinc-short / -medium / -long / -long-h
sinc-Mx / -MGa / -Ls / -Lm / -Lh
minringFIR-lp
```

依据 HQPlayer 手册的家族命名规则：
- `-short`≈4k / 基准≈32k / `-long`≈262k / `-xl`≈1M 抽头
- `-lp` 线性相位、`-mp` 最小相位、`-ip` 中间相位
- `-hires` 高码率优化（过渡带更宽）
- `-mqa/mp3` 为有损源优化（过渡带更宽，不追求陡峭）
- `halfband` 半带切趾（0.44~0.50 比例渐进滚降）

这些与既有条目**同一算法**，只是参数不同，所以只需验证频响，不需要新代码路径。

## 未做的 5 项（如实标注）

| 项 | 为什么不做 |
|---|---|
| `minphaseFIR` | HQPlayer 里这是**算法大类**（直接设计最小相位 FIR），不是某个窗的变体。我们已有 `-mp` 系列走的是「线性相位设计 + 希尔伯特变换」路径，结果等价但实现不同。要真做需另写一套直接设计器，收益有限。 |
| `FFT` | 同上，是「FFT 域卷积」这一大类（我们已有 FFT 分块卷积在 DSP 核心里，只是不作为一个"滤波器选项"暴露）。若要暴露，需要把卷积实现选型搬到 UI，属于架构改动。 |
| `polynomial-1/2` | 多项式插值（AQ / Spline），**不是 FIR**。需要新的插值器，与本项目的多相 FIR 结构并列存在。未实现。 |
| `ASRC` | 异步采样率转换（分数延迟 + 伺服环），是**硬件/SRC 芯片**级做法。本项目是同步软件重采样，引入 ASRC 会破坏 bit-perfect 判据（会引入不可控的采样率漂移）。**如实标注为不实现**。 |
