# RLPlayer 快速迭代计划（2026-10-21 重排）

> 用户要求：不再保守等待，快速补齐 HQPlayer 功能。每批 2–3 天可交付，
> 每个功能必须有客观判据；不做“同名假开关”。
> 当前基线：1.0.4 正式发布版（Full，555 MB），ctest 29/29。

## 原则

1. 先修现场，再堆功能；每批独立出 zip，版本号递增。
2. 一个功能一个判据：滤波看频响表，调制器看 SNR/空闲音/长跑，DSD 域看逐位/THD+N。
3. N 卡不靠 CUDA 唯一路径：用 D3D12 Compute 做 AMD/NVIDIA/Intel 通用后端；
   本机 AMD 可验证，N 卡内测直接反馈。CUDA 只在有工具链/测试卡时作为可选优化。
4. 不做假开关：UI 上的每个选项必须真的改变管线，并能在 /api/signal 或测试里看到。
5. NAA 继续押后；ZIP 交付，不做安装包。

## S1（2–3 天）：滤波器工厂（第一优先）

- FilterSpec：family / taps / transition / window / phase / twoStage / stage2Taps。
- 工厂 make_filter(FilterSpec)，所有预设共享设计与验证代码。
- 每个预设自动生成：抽头、通带最差、阻带最深、过渡带、相位、群延迟。
- 1x / Nx 独立选择；UI 按 family 分组。

第一批 ≥ 24 个预设：
poly-sinc lp/mp/short/long；poly-sinc-gauss / short / long / hires-lp / hires-mp；
ext2 / ext3；xtr-short-lp/mp、xtr-lp/mp；sinc-S/M/L/LL；
closed-form / fast / 16M；minringFIR / mp；hb-2s/4s/8s；hires-lp/mp。

判据：通带纹波 ≤0.01 dB；阻带 ≥100 dB（按预设 120/180 分档）；
过渡带与抽头单调；1x/Nx 真的改变 /api/signal；每个预设进 docs/滤波器矩阵.md。

## S2（2–3 天）：SDM 调制器族

- 5/7 阶 1-bit；EC（误差反馈）；AHM 多电平（2–8 bit）。
- 48k DSD 族（6.1/12.2 MHz）；DSD1024。
- 判据：DSD64/128/256，0 dBFS 不锁死；带内 SNR、带外噪声积分、空闲音、10 分钟长跑。
- 不复制 HQP 专有曲线；UI 标注“同类实现，非等价”。
- 保留自动降阶，但把原因写进信号链。

## S3（3–4 天）：DSD 域处理

- DSD→DSD 异速率（DSD64→128/256），不经过 PCM；DoP 标记合法、逐位可查。
- DSD→PCM：Integrator FIR/IIR/CIC + Noise filter + +6 dB 增益选项。
- DirectSDM 同速率逐位直通（已有），补 48k 族与多声道。
- 判据沿用 P0-4：通带平坦度、混叠抑制、THD+N；DSD→DSD 用位级/DoP 合法。

## S4（3–5 天）：N 卡兼容（D3D12 Compute）

- 新后端 rtagpu_dx12.dll：rta_gpu_available / rta_gpu_convolve / rta_gpu_resample。
- D3D12 + HLSL compute，运行时用 d3dcompiler_47.dll 编译；AMD/NVIDIA/Intel 通用。
- 先做卷积（IR <= 8192 直接 MAC；更大回退 CPU/FFT），再做多相升频。
- 加载顺序：HIP → D3D12 → CUDA → CPU；已改成逐个尝试，不再被第一个坏 DLL 卡死。
- 判据：与 CPU 参考相对误差 < 1e-4；AMD 本机实测；N 卡内测反馈。
- CUDA 后端仅在有 nvcc/测试卡时追加，不作为唯一 N 卡路径。

## S5（3–4 天）：播放器基本盘

- Gapless：下一首预解码 + 状态连续；同格式/同采样率无插入静音，DoP 标记连续。
- 设备热插拔/失效恢复：DEVICE_INVALIDATED、默认设备切换、独占被占用。
- 欠载直方图：事件超时、GetBuffer HRESULT、每事件实际写入帧数。
- DSD 性能：两级抽取（CIC 先降 4× 再 FIR），DSD256 5 分钟内存 < 200 MB。
- 解码去临时 WAV（FLAC/APE 管道）。
