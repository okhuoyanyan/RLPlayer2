# SDM 调制器实现纪要（Round 3）

代码：[src/dsp/modulator.h](src/dsp/modulator.h)　测试：[tests/test_modulator.cpp](tests/test_modulator.cpp)

## 1. 结构

误差反馈（STF = 1，信号平坦；NTF 为高通）：

```
w[n] = Σ_{k=1..N} p[k]·e[n-k] − Σ_{k=1..N} d[k]·w[n-k]
u[n] = x[n] + w[n]
y[n] = Q(u[n])
e[n] = y[n] − u[n]
⟹  Y(z) = X(z) + NTF(z)·E(z)
```

**关键点：w[n] 只依赖 e[n−1..] 与 w[n−1..]，严格因果。** 我曾把滤波器输出算在量化之后再用到下一拍，等于整体错开一拍——实测表现为 5 阶 1-bit 带内噪声只有 −53 dB。

NTF 设计：数字 Butterworth 高通
- `NTF(z) = B(z)/D(z)`，`B(z) = (1−z⁻¹)^N`（直流 N 阶零点）
- `D(z) = Π[(1−a_k) − (1+a_k)z⁻¹]`，`a_k = Ωc/p_k`，`Ωc = tan(π·fc/fs)`（双线性预畸变）
- 极点在单位圆内 ⟹ 环路稳定；出带增益 (1+r)^N/2^N 量级，对 1-bit 环路友好

## 2. 实测结果 @ DSD64 (2.8224 MHz)，NTF 拐点 100 kHz

| 配置 | 带内噪声 (0–20 kHz) | 带外噪声 | SNR | 稳定性 |
|---|---|---|---|---|
| **DSD5 1-bit（5 阶）** | **−95.2 dB** | −0.6 dB | **86.2 dB** | ✅ 0 次保护触发 |
| AHM5EC 5-level（5 阶/5 电平） | −72.6 dB | −13.5 dB | 63.6 dB | ✅ 稳定 |
| **AHM7EC 8-bit（7 阶/256 电平）** | **−127.9 dB** | −48.8 dB | **118.8 dB** | ✅ 稳定 |
| DSD7 1-bit（7 阶） | — | — | — | ❌ **满幅失稳** |

**NTF 设计验证**（1 kHz 处实测 vs 理论 (f/fc)^N）：

| 阶数 | 100 Hz | 1 kHz | 20 kHz | Nyquist |
|---|---|---|---|---|
| N=5 | −231.8 | **−197.0**（理论 −197.0）| −66.93 | +3.14 |
| N=7 | −6000（数值地板）| −181.5 | −93.74 | +4.36 |

## 3. ⚠️ 已知限制（如实记录，未粉饰）

1. **7 阶 1-bit 在满幅 0.5 时失稳**（保护触发 63902 次）。这是 1-bit 高阶调制器的固有难题：需要更高出带增益（H∞ ≈ 2）的 Chebyshev NTF + 环路定标，而我目前用的是 Butterworth 型（H∞ 仅 4.36 dB）。
2. **N=7 的 D 多项式展开仍受精度限制**：long double 让 1 kHz 处从 −87 dB 改善到 −181.5 dB，但 100 Hz 已触数值地板（−6000 dB）。彻底解决需改回**级联结构**（微分器链 + 全极点双二阶），该结构已验证响应正确（N=7 在 1 kHz = −182.2 dB），只是与严格因果的误差反馈回路配合需再推导一次。
3. **空闲音（idle tones）**：电平扫描显示 SNR 非单调（5 阶 1-bit：0.2 幅时 40.6 dB，0.4 幅时 96.9 dB）——存在与信号相关的离散音。我试过在量化器前注入抖动，但对 1-bit 量化器"1 LSB"= 满幅 2.0，注入即把 SNR 打到 −23 dB。**正确的做法是注入远小于 1 LSB 的微量抖动（1e-3 量级）或采用专门的空闲音抑制方案**，尚未实现。
4. **5 电平档只有 63.6 dB**，相对 8-bit 档偏低，需要重新设计该档的量化步长/抖动策略。

## 4. 对整体架构的意义

- **多电平 SDM 路线明显更优**：8-bit 档 SNR 118.8 dB 且完全稳定。这正好对应 HQPlayer 手册里的 AHM5EC5L / AHM7EC8B——说明官方把多电平当作高阶稳定性的解法，我们的实测支持这个判断。
- **1-bit 5 阶已达 86.2 dB**，是可用基线；要冲击 DSD256/512/1024，需要把 NTF 拐点按输出率等比上移（拐点相对 fs 的比例保持不变），并解决空闲音。
- 调制器是**逐样本串行**的（每样本 N 次乘加 + 量化），实测单核可跑 DSD64 立体声；DSD512 需评估，DSD1024 大概率要降档（与调研结论一致）。
