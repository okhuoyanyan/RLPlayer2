# Web 控制面纪要（Round 28）

代码：[src/net/webui.h](src/net/webui.h)、[tools/rtaplay.cpp](tools/rtaplay.cpp)

## 1. 用法

```powershell
rtaplay music.wav --web 8080            # 边播放边提供控制台
rtaplay music.wav --web-hold 8          # 只提供服务 8 秒，不播放（用于验证）
```

然后浏览器打开 http://127.0.0.1:8080/

## 2. 设计取舍

- **只监听 127.0.0.1** —— 控制面不该默认暴露到网络
- **阻塞式单线程 accept** —— 本地控制面并发极低，够用且零依赖
- **界面自包含** —— 无外部资源，离线可用
- **显式 UTF-8** —— 中文不乱码

`--web-hold` 模式**不打开音频设备、不播放**，可安全用于验证。

## 4. 已知边界

- 目前**只读**（状态查询）。配置下发（`POST /api/config`）尚未实现。
- 状态是**启动时快照**，不是播放中的实时状态 —— 因为管线当前是整块处理，没有流式进度。
  要做真正的实时状态，需要先把管线改成流式分块（与端点重构同类的改动）。
- 没有做请求体大小限制、并发保护等加固 —— 作为本地只读控制面可以接受，对外开放前必须补。
