# 时钟闭环控制器调优纪要（Round 20）

代码：[src/net/clock_loop.h](src/net/clock_loop.h)　测试：[tests/test_clock_loop.cpp](tests/test_clock_loop.cpp)

## 1. 修掉上一轮如实记录的两个缺陷

### 缺陷 1：漂移估计含自身修正量 ⟹ 正反馈

漂移估计测到的是**相对漂移**，其中已经包含我们上一拍施加的修正。直接按它补偿就形成正反馈——
实测内环增益取 1.0 时修正量在 **±337 ppm 之间来回甩**。

**修复**：先扣除自身修正，剩下的才是真实漂移。

```cpp
const double external = driftPpm - applied_;   // 关键一行
want += cfg_.innerGain * external;
```

扣掉之后内环增益可以安全地取满 1.0。

### 缺陷 2：外环纯 P ⟹ 稳态偏差

纯比例控制必然留下与漂移成正比的残余。**改为 PI**，并加积分抗饱和（±200 ppm）。

## 2. 效果对比（同一仿真，仅换控制器）

| 注入漂移 | 修复前偏差 | **修复后偏差** | 改进 |
|---|---|---|---|
| −20 ppm | 4.2 ms | **0.0 ms** | — |
| +20 ppm | 4.2 ms | **0.0 ms** | — |
| −50 ppm | 10.3 ms | **0.1 ms** | 100× |
| +50 ppm | 10.3 ms | **0.1 ms** | 100× |
| −100 ppm | 20.0 ms | **0.2 ms** | 100× |
| +100 ppm | 20.1 ms | **0.2 ms** | 100× |

**水位区间收敛到 [200, 200] ms** —— 稳定在目标值上，无溢出、无耗尽。
稳态修正量与漂移一致（+100 ppm 漂移 ⟹ +95.1 ppm 修正），方向与量级都正确。

修正量仍然平滑：**单步最大变化 0.053 ppm**（限幅 20 ppm/秒）。
测试容差同步从 25 ms **收紧到 8 ms**（实测 0.2 ms，留有充分余量）。
