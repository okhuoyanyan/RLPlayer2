## A. 真没做的功能（代码级缺口）

| # | 缺口 | 证据 | 影响 | 做起来需要 |
|---|---|---|---|---|
| A1 | **ASIO Native DSD** 未实现 | `src/audio/asio_out.h:14`；UI `ui_script.h:4323`「选 Native 不会出声」 | 有 ASIO 原生 DSD 的声卡只能用 DoP（占带宽、部分驱动不支持） | 需要一台支持 ASIOSTDSDInt8* 的卡做验证；无卡只能写不能证明 |

| A6 | **标准 NAA 握手** | ROADMAP P3；UI `ui_script.h:3754` | 只能用 RTANet 两机方案 | **外部阻塞**：networkaudiod EULA 禁止逆向，需 HQPlayer 会话抓包或用户授权 |
| A7 | **Intel / 其它 GPU 的计算后端**（D3D12 / oneAPI） | 只有 `rtagpu.dll`(AMD HIP) 与 `rtagpu_cuda.dll`(NVIDIA) | Intel Arc / 核显用户只能纯 CPU | 高：新后端 + 验证矩阵；收益取决于用户群 |
| A8 | **封面不写回文件**；PICTURE 畸形 FLAC 写回被拦 | 元数据文档 §1.6.E #3 | 补全的封面只存在库里，不进文件 | 中：FLAC PICTURE 重嵌 + 畸形保护 |
